# UPI-Shield 🛡️
Contextual Digital Payment Scam & Coercion Detector built for CC x GFG Hackathon.

## Features
- Ingests SMS, WhatsApp notes, or raw payment text
- Detects psychological coercion, urgency triggers, and impersonation via Gemini
- Real-time Threat Meter (High / Medium / Low)
- Bilingual actionable safety cards (English & Hindi)

## Quickstart
1. Clone repo: `git clone <YOUR-REPO-URL>`
2. Create virtual environment: `python -m venv venv && source venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`
4. Set API key: `export GEMINI_API_KEY="your-api-key"`
5. Run application: `streamlit run app.py`
